Response workflow

From request to response.

A structured workflow helps emergency coordinators move from incoming requests to volunteer assignment and resource coordination.

01

Report

A person submits an emergency request with the information required for response coordination.

02

Assess

Coordinators review the request, urgency and location before deciding the appropriate response.

03

Coordinate

Available volunteers and resources can be identified and assigned to active emergencies.

04

Respond

Response status can be tracked as the emergency moves toward completion.
